# Algoritmo

## O que é

Um algoritmo é uma sequência finita e bem definida de instruções para resolver um problema ou
realizar uma tarefa. A ideia não é exclusiva da computação: uma receita de bolo também é um
algoritmo — uma sequência de passos que, seguidos na ordem certa, produz um resultado esperado. Em
computação, os algoritmos são a base de qualquer programa: definem, passo a passo, como processar
uma entrada de dados até chegar a um resultado.

## Por que isso importa?

Toda ferramenta digital — de um gerenciador de referências a um modelo de reconhecimento de fala —
executa algum algoritmo por trás da interface. Entender o que é um algoritmo ajuda a interpretar
criticamente por que uma ferramenta se comporta de determinada forma: por que um mecanismo de busca
ordena resultados de um jeito e não de outro, por que uma transcrição automática erra em certos
trechos, ou por que um sistema de recomendação sugere certos itens em vez de outros. É também a
base para entender conceitos mais avançados do glossário, como aprendizado de máquina e modelo.

## Exemplo

Um pesquisador usa um gerenciador de referências que organiza automaticamente sua bibliografia em
ordem alfabética. O programa segue um algoritmo de ordenação — uma sequência de comparações entre
nomes de autores — para decidir a posição de cada item na lista. O pesquisador não vê esses passos,
mas é esse algoritmo que garante que a bibliografia apareça organizada corretamente.

## Não confunda com

Algoritmo não é sinônimo de programa nem de [inteligência artificial](inteligencia-artificial.md). Um **programa** é a
implementação concreta de um ou mais algoritmos em uma linguagem de programação específica; um
mesmo algoritmo pode ser implementado em programas diferentes. Já **inteligência artificial** é um
campo que usa determinados tipos de algoritmo (entre outras técnicas) para tarefas específicas —
mas a maioria dos algoritmos que existem (como o de ordenar uma lista) não tem nenhuma relação com
IA.
