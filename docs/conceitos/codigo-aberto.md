# Código Aberto

## O que é

Código aberto (*open source*) é uma forma de licenciamento de software em que o código-fonte é disponibilizado publicamente, com permissão explícita para qualquer pessoa usar, estudar, modificar e redistribuir o programa. Segundo a Open Source Initiative (OSI) — organização que mantém a definição de referência do termo desde 1998 —, os termos de distribuição de um software de código aberto devem cumprir uma série de critérios, entre eles a "redistribuição livre": os direitos associados ao programa não podem depender de ele fazer parte de uma distribuição específica, e qualquer pessoa que o receba deve ter os mesmos direitos concedidos originalmente. A definição completa da OSI (a "Open Source Definition") tem dez critérios, cobrindo desde acesso ao código-fonte até a proibição de discriminar pessoas ou campos de uso.

## Por que isso importa?

Muitas ferramentas usadas em pesquisa e ensino em Humanidades — de gerenciadores de referências a softwares de análise de texto — são de código aberto, o que traz vantagens específicas para o contexto acadêmico: possibilidade de auditar como a ferramenta processa os dados, adaptá-la a necessidades específicas de um projeto de pesquisa, e reduzir a dependência de uma única empresa fornecedora. Entender que "código aberto" tem um significado técnico preciso — definido por critérios formais da OSI, não apenas "gratuito" — ajuda a avaliar com mais precisão o tipo de acesso e as licenças declaradas nos verbetes deste glossário.

## Exemplo

O [Zotero](../ferramentas/zotero.md) e o [JabRef](../ferramentas/jabref.md) são gerenciadores de referências de código aberto: qualquer pessoa pode acessar o código-fonte desses programas em repositórios públicos, propor modificações, ou adaptar o software para uma necessidade específica de um projeto de pesquisa — diferente de ferramentas proprietárias, como o [Mendeley](../ferramentas/mendeley.md), cujo código-fonte não é público.

## Não confunda com

Código aberto não é sinônimo de [software livre](software-livre.md): embora os dois termos frequentemente descrevam, na prática, categorias de licenças sobrepostas, código aberto é definido pela Open Source Initiative com critérios voltados a práticas de desenvolvimento colaborativo e uso prático; software livre é definido pela Free Software Foundation com ênfase em quatro liberdades fundamentais da pessoa usuária, numa perspectiva mais filosófica sobre autonomia e ética. Também não é sinônimo de gratuito: um software pode ser de código aberto e ainda assim envolver custos (por exemplo, de suporte ou hospedagem), assim como um software gratuito pode não ser de código aberto.
