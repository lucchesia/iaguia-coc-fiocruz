# Dados

## O que é

Dados são representações formalizadas de algo — números, palavras, imagens, sons — organizadas de um jeito que permite comunicá-las, interpretá-las ou processá-las. Segundo a norma internacional ISO/IEC/IEEE 15939:2017 (adotada pelo NIST), dados são uma "representação reinterpretável de informação de maneira formalizada, adequada para comunicação, interpretação ou processamento". Por si só, um dado não tem significado automático: "1822" é apenas uma sequência de dígitos até que alguém a interprete dentro de um contexto.

## Por que isso importa?

Pesquisa em Humanidades cada vez mais trabalha com "dados de pesquisa" — transcrições, planilhas, catálogos de acervo, imagens digitalizadas, entrevistas transformadas em texto. Entender que dados, por si só, não carregam significado automático ajuda a avaliar criticamente ferramentas que processam grandes volumes de dados automaticamente: elas podem produzir resultados tecnicamente corretos, mas sem sentido histórico ou interpretativo, se o contexto da fonte não for considerado por quem pesquisa.

## Exemplo

O número "1822" é um dado. A frase "1822 é o ano da independência do Brasil" é informação — o mesmo dado, interpretado dentro de um contexto que lhe dá significado. Um catálogo de um acervo digitalizado é cheio de dados desse tipo: nomes, datas, números de inventário, coordenadas geográficas — que só se tornam informação útil quando uma pessoa pesquisadora os interpreta à luz de uma pergunta de pesquisa.

## Não confunda com

Dados não é sinônimo de informação: o dado é a representação bruta (um número, uma palavra, um valor); informação é o dado já interpretado, com significado atribuído dentro de um contexto — a mesma sequência de dados pode virar informações diferentes dependendo de quem a interpreta e por quê. Dados também não é sinônimo de [metadados](metadados.md): metadados são dados que descrevem outros dados (por exemplo, o nome do fotógrafo e a data de captura de uma fotografia são metadados sobre a fotografia — que é, ela mesma, o dado).
