# Dublin Core

## O que é

Dublin Core é um padrão de metadados formado por um conjunto simples de elementos descritivos — como título, autor, data, formato e assunto — usado para descrever recursos digitais de forma padronizada, permitindo que diferentes sistemas "conversem" entre si. É mantido pela Dublin Core Metadata Initiative (DCMI), organização internacional descrita, em seu próprio site, como "um fórum aberto dedicado à inovação em metadados e ao apoio ao desenvolvimento de padrões de metadados interoperáveis". O padrão original, o Dublin Core Metadata Element Set, tem 15 elementos básicos e é reconhecido internacionalmente pelas normas ISO 15836 e ANSI/NISO Z39.85.

## Por que isso importa?

Dublin Core é um dos padrões de metadados mais amplamente adotados em bibliotecas, arquivos e repositórios digitais, justamente por sua simplicidade e ampla compatibilidade. Para pesquisa, entender que ferramentas de gestão de acervos costumam usar Dublin Core como base para seus campos de descrição ajuda a entender por que é possível migrar ou combinar coleções entre plataformas diferentes sem perder a estrutura essencial da informação descritiva.

## Exemplo

Ao catalogar uma fotografia histórica no [Omeka S](../ferramentas/omeka-s.md), uma pesquisadora preenche campos baseados em Dublin Core — título, criador, data, assunto — que seguem o mesmo padrão usado por milhares de outras instituições ao redor do mundo, permitindo que essa descrição seja compreendida e reaproveitada por outros sistemas compatíveis com Dublin Core.

## Não confunda com

Dublin Core não é sinônimo de metadados em geral: metadados é o conceito amplo de "dados sobre dados"; Dublin Core é um padrão específico e formal para estruturar esse tipo de informação, entre vários outros existentes (como MODS ou EAD, mais especializados). Também não é sinônimo de IIIF: Dublin Core padroniza a descrição de recursos em geral; IIIF padroniza especificamente a entrega de imagens digitais — os dois podem ser usados juntos, mas resolvem problemas diferentes.
