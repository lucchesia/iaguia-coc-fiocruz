# Conceitos e termos

O vocabulário mínimo para compreender e avaliar criticamente as tecnologias que entram na
pesquisa e no ensino: conceitos de [inteligência artificial](inteligencia-artificial.md), de
computação e de cultura digital, em linguagem acessível para quem trabalha nas Humanidades, com
qualquer nível de letramento digital.

A coleção se ocupa de manter distinções que o uso cotidiano apaga. Todo sistema digital usa
[algoritmo](algoritmo.md), e nem todo algoritmo envolve inteligência artificial. O
[modelo](modelo.md) não se confunde com a ferramenta pela qual se fala com ele.

Use o menu **Conceitos e termos** no topo da página para navegar pela lista em ordem alfabética.
Quando um conceito ajuda a entender um programa específico, o verbete aponta para a coleção
[Ferramentas](../ferramentas/index.md).

Se preferir partir da tarefa em vez da lista alfabética, use a página
[Encontre uma ferramenta ou conceito](../encontrar.md).

Está faltando um termo? [Sugira um novo verbete pelo formulário de contribuição](../contribuir.md).
