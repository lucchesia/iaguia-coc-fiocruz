# Software Livre

## O que é

Software livre é um software cujas pessoas usuárias têm garantidas quatro liberdades fundamentais, segundo a definição da Free Software Foundation (FSF): a liberdade de executar o programa como desejar, para qualquer finalidade (liberdade 0); a liberdade de estudar como o programa funciona e alterá-lo conforme necessário, com acesso ao código-fonte como condição para isso (liberdade 1); a liberdade de redistribuir cópias, para ajudar outras pessoas (liberdade 2); e a liberdade de distribuir cópias de versões modificadas (liberdade 3). Segundo a FSF, um programa só é software livre se garante essas quatro liberdades a todas as pessoas usuárias.

## Por que isso importa?

A distinção entre software livre e código aberto, embora sutil, reflete duas tradições e ênfases diferentes dentro do mesmo movimento: a Free Software Foundation enfatiza a dimensão ética e política da liberdade da pessoa usuária diante do software que usa; a Open Source Initiative enfatiza vantagens práticas do desenvolvimento colaborativo. Para pesquisa em Humanidades, essa dimensão é relevante ao avaliar, por exemplo, ferramentas que processam dados sensíveis de entrevistas ou fontes de arquivo: o controle sobre o funcionamento do software pode ser um critério ético relevante, não apenas técnico.

## Exemplo

O [OpenRefine](../ferramentas/openrefine.md) e o [QGIS](../ferramentas/qgis.md) são exemplos de software livre usados em pesquisa: além do código-fonte ser aberto, esses programas garantem às pessoas usuárias a liberdade de executá-los para qualquer finalidade, estudá-los, modificá-los e redistribuir versões modificadas — sem restrições impostas por uma empresa detentora dos direitos.

## Não confunda com

Software livre não é sinônimo de [código aberto](codigo-aberto.md): os dois termos frequentemente descrevem softwares licenciados de forma equivalente na prática, mas partem de definições formais distintas — mantidas por organizações diferentes (FSF e OSI), com ênfases diferentes. Também não é sinônimo de gratuito: a palavra "livre", nesse contexto, se refere a liberdade (como em "liberdade de expressão"), não a preço — um software livre pode ser vendido, desde que as quatro liberdades sejam preservadas para quem o recebe.
