## O que é

EndNote é um programa de gerenciamento de referências bibliográficas mantido pela Clarivate (a mesma empresa por trás da base de dados Web of Science). Permite organizar bibliotecas de referências, anotar PDFs e inserir citações formatadas automaticamente em textos acadêmicos. É uma das ferramentas mais tradicionais da área, amplamente usada em universidades e bibliotecas institucionais.

## Para que serve

- Organizar referências bibliográficas em bibliotecas, com milhares de estilos de citação disponíveis
- Anotar e destacar PDFs anexados às referências
- Inserir citações e gerar bibliografias automaticamente em documentos do Word, com o plugin Cite While You Write
- Sincronizar a biblioteca entre o aplicativo de desktop, a versão web (EndNote Online) e o app para iPad
- Colaborar com grupos de pesquisa compartilhando bibliotecas
- Na versão mais recente, usar recursos de IA para resumir artigos e conversar com o texto completo de um documento (EndNote Research Assistant)

## Exemplo de uso

Uma equipe de pesquisa de uma universidade está escrevendo um artigo em coautoria para uma revista científica. Cada integrante importa referências para uma biblioteca compartilhada do EndNote, e, ao escrever no Word, insere citações automaticamente no estilo exigido pela revista (por exemplo, Vancouver) usando o plugin Cite While You Write — sem precisar formatar a bibliografia manualmente.

## Quando pode não ser a melhor opção

- Se você usa Linux: o aplicativo de desktop do EndNote só roda em Windows e macOS — não há versão para Linux
- Se você escreve em Google Docs: não há integração oficial com Google Docs (diferente de outras ferramentas da área)
- Se você busca uma opção totalmente gratuita: a versão gratuita (EndNote Basic/Online) é limitada — 50 mil referências, 2 GB de anexos, poucos estilos de citação — e o aplicativo de desktop completo exige compra
- Se o orçamento inicial for uma limitação: diferente de concorrentes com assinatura mensal, o EndNote desktop é vendido como licença única (a partir de aproximadamente R$ 1.586 na compra completa, com desconto para estudantes), o que pode compensar a longo prazo, mas representa um custo inicial mais alto

## Tipo de acesso

Freemium. O EndNote Online (ou "EndNote Basic") é gratuito e disponível para qualquer pessoa, mas limitado a 50 mil referências, 2 GB de anexos e poucos estilos de citação. O aplicativo de desktop completo é pago, vendido como licença única (não por assinatura): cerca de R$ 1.586 na compra completa, R$ 865 para estudantes e R$ 721 para upgrade de versões anteriores (valores de referência, sujeitos a variação por região e promoções). Instituições podem negociar licenças de volume. O software é proprietário, não código aberto.

## Sistemas em que roda

Windows e macOS (aplicativo de desktop), além da versão web (EndNote Online, acessível por navegador) e de um aplicativo gratuito para iPad. Não há versão para Linux.

## Integrações

- Microsoft Word (plugin Cite While You Write, para Windows e macOS)
- LibreOffice Writer (apenas no Windows)
- Sem integração oficial com Google Docs

## Alternativas

- [Zotero](zotero.md) (código aberto, gratuito, sem vínculo com uma editora comercial)
- [Mendeley](mendeley.md) (freemium, mantido pela Elsevier)
- [JabRef](jabref.md) (código aberto, foco em BibTeX/LaTeX)
- [Paperpile](paperpile.md) (pago por assinatura, integrado ao Google Docs)

## Observações

O EndNote é uma das ferramentas de gestão de referências mais antigas e tradicionalmente adotadas em universidades, especialmente nas áreas médica e científica, muitas vezes disponibilizado via licença institucional da biblioteca. É mantido pela Clarivate, a mesma empresa responsável pelo Web of Science — o que levanta, como no caso do Mendeley/Elsevier, questões sobre concentração de dados de pesquisa em grandes empresas do setor acadêmico. A versão 2025 introduziu recursos de [inteligência artificial](../conceitos/inteligencia-artificial.md) (resumo de artigos, "chat" com o texto completo de documentos), acompanhando uma tendência já vista em outras ferramentas da área.
