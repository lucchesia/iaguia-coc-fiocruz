# Ferramentas

Ferramentas digitais para pesquisa, ensino, organização, análise, escrita, transcrição,
visualização, gestão de referências e outras atividades relevantes para Humanidades — não apenas
ferramentas de [inteligência artificial](../conceitos/inteligencia-artificial.md).

Use o menu **Ferramentas** no topo da página para navegar pela lista em ordem alfabética. Quando um
verbete menciona um conceito técnico com explicação própria, ele aponta para a coleção
[Conceitos e termos](../conceitos/index.md).

Se preferir partir da tarefa em vez da lista alfabética, use a página
[Encontre uma ferramenta ou conceito](../encontrar.md).

Está faltando uma ferramenta? [Sugira um novo verbete pelo formulário de contribuição](../contribuir.md).
