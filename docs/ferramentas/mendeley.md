## O que é

Mendeley é um gerenciador de referências bibliográficas mantido pela Elsevier (grupo RELX). Permite coletar, organizar, anotar e citar referências acadêmicas, com sincronização entre o aplicativo de computador e a versão web. Também oferece, em planos pagos, recursos de [inteligência artificial](../conceitos/inteligencia-artificial.md) para buscar e resumir informações dentro da própria biblioteca de referências.

## Para que serve

- Importar referências e PDFs diretamente do navegador, com a extensão Web Importer
- Organizar a biblioteca em pastas, anotar e destacar PDFs
- Inserir citações e gerar bibliografias automaticamente em textos do Word, usando o plugin Mendeley Cite
- Sincronizar a biblioteca entre o aplicativo de desktop (Windows, macOS, Linux) e a versão web
- Compartilhar bibliotecas com grupos de pesquisa para colaboração
- Nos planos pagos, consultar e comparar a própria biblioteca com recursos de IA (Reading Assistant, Ask My Library)

## Exemplo de uso

Um pesquisador está revisando a literatura para um artigo sobre historiografia digital. Ao navegar por bases como o Google Scholar, ele usa o Web Importer do Mendeley para salvar os artigos relevantes com um clique. Depois, ao escrever o artigo no Word, insere as citações e gera a bibliografia automaticamente no estilo ABNT usando o plugin Mendeley Cite.

## Quando pode não ser a melhor opção

- Se você escreve em Google Docs ou LibreOffice: o plugin atual (Mendeley Cite) funciona só com Microsoft Word. A integração com LibreOffice existe apenas no plugin de citação mais antigo, vinculado ao Mendeley Desktop (versão legada, sem novos recursos). Não há integração oficial com Google Docs
- Se você prioriza software livre e independência de uma grande editora comercial de periódicos: o Mendeley é proprietário e mantido pela Elsevier
- Os recursos de IA (Reading Assistant, Ask My Library) são limitados a 5 usos no plano gratuito — uso ilimitado exige assinatura paga a partir de US$ 4,99/mês

## Tipo de acesso

Freemium. O plano gratuito inclui 2 GB de armazenamento e acesso limitado (5 perguntas) ao recurso de IA "Reading Assistant". Os planos pagos — Plus (US$ 4,99/mês, 5 GB), Pro (US$ 9,99/mês, 10 GB) e Max (US$ 14,99/mês, armazenamento ilimitado) — ampliam o armazenamento e liberam uso ilimitado dos recursos de IA. O software em si é proprietário, não código aberto.

## Sistemas em que roda

Windows, macOS e Linux (aplicativo de desktop Mendeley Reference Manager), além de versão web pelo navegador e extensão Web Importer para captura de referências. Não há mais aplicativo oficial para iOS ou Android — os apps móveis foram descontinuados em 2021.

## Integrações

- Microsoft Word (plugin Mendeley Cite, para inserir citações e gerar bibliografia)
- LibreOffice Writer (apenas via plugin de citação mais antigo, distribuído com o Mendeley Desktop legado — não com o Mendeley Cite atual)
- Sem integração oficial com Google Docs (existem extensões não oficiais de terceiros)

## Alternativas

- [Zotero](zotero.md) (código aberto, gratuito, sem vínculo com uma editora comercial)
- [JabRef](jabref.md) (código aberto, foco em BibTeX/LaTeX)
- [EndNote](endnote.md) (pago, licença institucional comum em universidades)
- [Paperpile](paperpile.md) (pago, integrado ao Google Docs)

## Observações

Mendeley é mantido pela Elsevier, uma das maiores editoras acadêmicas do mundo — o que gera, para parte da comunidade acadêmica, preocupação com a concentração de dados de pesquisa em uma editora comercial. O produto teve historicamente um componente de rede social acadêmica (perfis, grupos públicos), hoje reduzido em favor da gestão de referências e, mais recentemente, de recursos de IA vendidos por assinatura. O "Mendeley Desktop", antecessor do atual Mendeley Reference Manager, ainda recebe suporte básico para quem depende dele, mas não recebe novos recursos.
