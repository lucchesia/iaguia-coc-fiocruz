## O que é

Taguette é um programa gratuito e de código aberto para análise qualitativa de texto, criado por Rémi Rampin com apoio da equipe de bibliotecas da Universidade de Nova York (NYU). Permite destacar trechos de documentos e marcá-los com códigos (tags) definidos pela própria pessoa pesquisadora — o método de codificação usado em pesquisa qualitativa. Foi criado explicitamente como alternativa a programas comerciais caros como NVivo e ATLAS.ti, para pesquisadores sem grandes orçamentos de pesquisa.

## Para que serve

- Importar documentos em vários formatos (PDF, Word, TXT, HTML, EPUB, MOBI, ODT, RTF) para codificação
- Destacar palavras, frases ou parágrafos e marcá-los com códigos criados pela própria pessoa pesquisadora
- Organizar códigos com descrições e cores, para facilitar a leitura visual da codificação
- Exportar documentos codificados, destaques de um código específico, a lista de códigos ou o projeto inteiro
- Trabalhar tanto localmente (instalado no próprio computador) quanto em uma versão hospedada gratuita (app.taguette.org), sem precisar instalar nada

## Exemplo de uso

Uma pesquisadora está analisando quarenta entrevistas transcritas sobre memória de um evento histórico local. Ela importa as transcrições no Taguette e, à medida que lê cada uma, destaca trechos relevantes e os marca com códigos que vai criando conforme temas emergem (por exemplo, "medo", "solidariedade", "desconfiança institucional"). Ao final, exporta todos os trechos marcados com o código "solidariedade" para reunir, num único documento, todas as passagens relacionadas a esse tema em todas as entrevistas.

## Quando pode não ser a melhor opção

- Se você precisa de recursos estatísticos avançados sobre a codificação (análise de frequência cruzada entre códigos, visualizações complexas): ferramentas comerciais como NVivo ou ATLAS.ti, ou o QualCoder (também gratuito), oferecem mais recursos analíticos
- Se você prefere um programa totalmente instalado no computador, sem depender de servidor: a versão hospedada (app.taguette.org) é conveniente, mas envia os documentos a um servidor de terceiros — para dados sensíveis, a instalação local é mais indicada
- Se você já é experiente com ferramentas de QDA (Qualitative Data Analysis) mais robustas: o Taguette é deliberadamente mais simples, o que é uma vantagem para iniciantes, mas pode limitar projetos muito complexos

## Tipo de acesso

Totalmente gratuito e de código aberto (licença BSD 3-Clause). Pode ser usado na versão hospedada gratuita (com cadastro) ou instalado localmente/em servidor próprio.

## Sistemas em que roda

Windows, macOS e Linux (instalação local), além de acesso via navegador na versão hospedada.

## Integrações

Não tem integrações formais conhecidas com outras ferramentas — funciona como programa independente para importação, codificação e exportação de documentos.

## Alternativas

- [QualCoder](qualcoder.md) (também gratuito e de código aberto, com recursos analíticos adicionais)
- NVivo (proprietário, pago, referência comercial em análise qualitativa)
- ATLAS.ti (proprietário, pago, outra referência comercial no campo)

## Observações

O Taguette nasceu de uma motivação explicitamente declarada pela equipe: tornar a análise qualitativa acessível a pesquisadores sem recursos para licenças caras de software comercial. É uma opção especialmente relevante para pesquisa em história oral, memória e outras áreas que trabalham com codificação temática de entrevistas e depoimentos, quando o orçamento do projeto não comporta ferramentas proprietárias.
