## O que é

Tropy é um programa gratuito e de código aberto para organizar e anotar fotografias de documentos de arquivo. Foi desenvolvido pela Roy Rosenzweig Center for History and New Media (a mesma instituição por trás do Zotero) especificamente para atender às necessidades de pesquisadores que acumulam centenas ou milhares de fotos tiradas em arquivos históricos. Permite adicionar metadados, transcrições e notas a cada imagem ou conjunto de imagens.

## Para que serve

- Organizar grandes volumes de fotografias tiradas em arquivos, bibliotecas e acervos
- Adicionar metadados descritivos às imagens (título, data, instituição de origem, coleção, etc.)
- Agrupar várias fotos de um mesmo documento em um único item
- Anotar imagens com transcrições parciais ou notas de pesquisa
- Criar listas e coleções temáticas dentro de um projeto de pesquisa
- Exportar dados e metadados para outros programas

## Exemplo de uso

Um pesquisador passou três semanas em um arquivo provincial fotografando processos judiciais do século XIX. Ao voltar, tem 2.000 fotos em pastas no computador, sem organização. No Tropy, ele importa todas as imagens e as agrupa por processo. Para cada processo, adiciona campos como número, data, comarca e nomes das partes. Semanas depois, ao escrever o artigo, consegue localizar qualquer documento em segundos e reler suas anotações.

## Quando pode não ser a melhor opção

- Se você precisa de transcrição automática das imagens: o Tropy organiza e anota, mas não transcreve automaticamente — para isso, use o [Transkribus](transkribus.md) ou o [Whisper](whisper.md)
- Se suas fotos de arquivo são poucas (menos de algumas dezenas): uma pasta organizada no computador com bom sistema de nomenclatura pode ser suficiente
- Se você precisa publicar os documentos online para um público amplo: o Tropy é uma ferramenta de pesquisa pessoal, não uma plataforma de publicação — para isso, considere o Omeka
- Não tem aplicativo para celular; o trabalho é feito no computador

## Tipo de acesso

Gratuito e de código aberto (licença AGPL). Sem custo algum. Os dados ficam armazenados localmente no computador do pesquisador, em um arquivo de projeto criado pelo próprio Tropy.

## Sistemas em que roda

Windows, macOS e Linux.

## Integrações

- [Zotero](zotero.md): é possível vincular itens do Tropy a referências do Zotero, conectando o documento primário à sua ficha bibliográfica
- Omeka: exportação de itens para publicação em plataforma digital (via plugin)

## Alternativas

- digiKam (código aberto, mais voltado para fotografia em geral, não específico para pesquisa histórica)
- Adobe Bridge (proprietário, pago via Creative Cloud)
- Lightroom (proprietário, pago, mais voltado para edição fotográfica)
- Organização manual com pastas e nomenclatura sistemática de arquivos (sem programa específico)

## Observações

Tropy resolve um problema muito específico e recorrente na pesquisa histórica: o caos de fotos de arquivo sem organização. Por ter sido desenvolvido por e para historiadores, sua lógica de metadados e organização é compatível com o modo como pesquisadores pensam sobre fontes primárias. Como os dados ficam salvos localmente, não há preocupação com privacidade ou acesso de terceiros. A integração com o Zotero é um diferencial importante para quem já usa esse gerenciador de referências.
